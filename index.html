Project Database

Hubungkan ke Google Sheets yang dipublish sebagai CSV — gratis, tanpa API Key, data selalu sinkron.

📋 Cara Setup Google Sheets

1Buka Google Sheets Anda → klik menu File
2Pilih Share → Publish to web
3Di dropdown kiri pilih nama sheet/tab yang ingin dipublish
4Di dropdown kanan pilih Comma-separated values (.csv)
5Klik Publish → copy link yang muncul → paste di bawah
6Aktifkan "Automatically republish when changes are made" agar otomatis update
📌 Format kolom spreadsheet (baris 1 = header):
A: No  |  B: Nama Proyek  |  C: Jenis  |  D: Deskripsi  |  E: Link Spreadsheet  |  F: Link Web/HTML  |  G: Link Apps Script  |  H: Status  |  I: Tanggal Update  |  J: Keterangan
Link yang didapat dari File → Share → Publish to web → CSV
